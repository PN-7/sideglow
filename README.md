# Sideglow

**한국어** | [日本語](README.ja.md) | [English](README.en.md)

**게임 화면 위에서 사용하는 Discord 채팅·번역 오버레이**

Sideglow는 Discord 채널의 대화를 게임 화면 위에 표시하고, 단축키로 메시지를 보낼 수 있는 Windows용 채팅창입니다. 선택적으로 AI 번역을 켜면 서로 다른 언어로 작성한 대화와 번역문을 함께 확인할 수 있습니다.

Rust와 Windows 네이티브 UI로 구현했으며, 작은 창과 필요한 기능에 집중합니다. Discord PC 앱과 함께 사용하며, 게임 자체의 채팅을 읽거나 화면을 OCR로 번역하는 기능은 제공하지 않습니다.

> **[Sideglow](https://github.com/PN-7/sideglow/releases)**

## 시작하기 전에

**Discord PC 클라이언트를 설치하고, 사용할 계정으로 로그인한 상태에서 실행해 두어야 합니다.** Sideglow는 이 PC 앱을 통해 채널 메시지를 받습니다. 브라우저판이나 모바일 Discord만 실행한 상태로는 사용할 수 없습니다.

| 준비 항목 | 필요한 내용 |
|---|---|
| 운영체제 | 인터넷에 연결된 Windows 10/11 64비트 PC |
| Discord PC 앱 | 설치·로그인을 마치고 실행 중이어야 합니다. [Discord 다운로드](https://discord.com/download) |
| Discord 계정 | 사용할 서버와 텍스트 채널에 접근할 수 있어야 합니다. 브라우저 승인과 PC 앱에서 같은 계정을 사용하세요. |
| 연결 정보 | 운영자나 친구에게 받은 연결 코드, 또는 Discord 애플리케이션 ID와 채널 링크 |
| 메시지 전송 | 같은 채널의 웹후크 URL이 추가로 필요합니다. 웹후크가 없으면 수신 전용으로 사용합니다. |
| 게임 화면 모드 | 창 모드 또는 테두리 없는 창 모드를 기준으로 설계했습니다. |
| AI 번역 — 선택 사항 | 번역을 담당하는 한 사람만 선택한 API 제공사의 키가 필요합니다. OpenAI, OpenAI 호환 서비스, Anthropic, Gemini를 지원하며 결과를 받기만 하는 사람에게는 키가 필요하지 않습니다. |

**현재 연결 방식에는 Discord의 앱 권한 제한이 있습니다.** 채팅을 받아오는 RPC 권한은 앱의 승인 조건에 영향을 받습니다. Discord 앱을 만들거나 테스터 초대를 수락했다는 이유만으로 모든 계정의 연결이 보장되지는 않습니다. 처음 준비하는 사람은 친구에게 배포하기 전에 본인과 친구 계정에서 실제 수신을 확인하세요. 자세한 절차는 [Discord 연결 안내](docs/SETUP.md)에 있습니다. 권한의 범위는 [Discord 공식 OAuth2 문서](https://docs.discord.com/developers/topics/oauth2)를 참고하세요.

## 주요 기능

- **게임 위 채팅 표시:** Discord 채널의 원문과 번역 답글을 함께 확인합니다. 작성자는 웹후크 접두부를 뺀 닉네임으로, 메시지 시각은 Windows 현지 시간으로 표시합니다.
- **단축키로 입력:** 지정한 게임에서 기본 `Enter`로 입력창을 엽니다. 단축키는 설정에서 변경할 수 있습니다.
- **클릭 통과와 창 편집:** 평소에는 마우스 클릭을 게임으로 전달하고, `Alt+Tab`으로 Sideglow를 선택하면 창을 이동하거나 가장자리를 드래그해 크기를 조절합니다.
- **채널 탭:** 최대 8개 채널을 저장합니다. 선택한 탭 하나만 실시간으로 수신·번역합니다.
- **읽기 편한 화면 설정:** 시스템 글꼴, 글자 크기, 본문·발언자·번역문 색상, 자간·줄 간격, 글자 테두리, 배경색·불투명도를 조절합니다. 모양 변경은 저장 전에도 미리 볼 수 있습니다.
- **오래된 대화 숨기기:** 설정한 시간이 지난 대화를 화면에서 차례로 숨깁니다. Discord 채널의 실제 메시지는 유지됩니다.
- **선택적 AI 번역:** OpenAI, OpenAI 호환 서비스, Anthropic, Gemini 중 하나를 선택해 한 사람의 API 키로 채널의 새 대화를 번역합니다. 모두가 결과를 받으며 관리 화면에서 번역을 켜고 끌 수 있습니다.
- **개인별 로마자 일본어 옵션:** 알파벳으로 일본어를 입력하는 사람만 설정의 **내 메시지의 로마자 일본어 판별**을 체크하고 저장합니다. 기본값은 해제이며, 번역을 맡지 않은 사람도 선택할 수 있습니다.
- **화면 언어:** 한국어·일본어·영어를 제공합니다. UI 문구는 외부 JSON 파일로 편집할 수 있습니다.

## 다운로드와 실행

Windows x64용 실행 파일은 [GitHub Releases](https://github.com/PN-7/sideglow/releases)에서 다운로드할 수 있습니다. 배포 ZIP을 다운로드한 후 압축을 풀어 사용하세요.

GitHub의 **Code → Download ZIP**은 실행 파일이 아닌 소스 코드 압축 파일입니다. 직접 빌드하려면 아래의 [소스에서 빌드하기](#소스에서-빌드하기)를 참고하세요.
Windows x64용 실행 파일이 포함된 배포 ZIP을 받은 경우:

1. Windows x64용 Sideglow 배포 ZIP을 준비합니다.
2. ZIP의 압축을 풀고, 실행 파일과 `locales` 폴더를 같은 폴더에 둡니다.
3. Discord PC 앱에 로그인한 뒤 실행 파일을 엽니다. 실행 파일 이름은 `sideglow.exe`입니다.
4. 아래의 연결 절차를 진행합니다. 업데이트할 때는 기존 프로그램을 완전히 종료한 뒤 새 버전을 실행하세요.

실행 파일로 사용하는 경우 Rust나 Node.js를 따로 설치할 필요는 없습니다. `start-demo.cmd`는 예제 화면을 확인하는 용도이며, 실제 Discord 연결에는 일반 실행 파일을 사용합니다.

## 친구에게 연결 정보를 받은 경우

1. **설정 → 처음 연결 / 로그인… → 친구에게 받은 코드·링크로 연결**을 엽니다.
2. **연결 코드 붙여넣기… → 코드 붙여넣기 → 설정에 채우기**로 받은 코드를 적용합니다. 앱 ID·채널 링크·웹후크 URL을 직접 입력해도 됩니다. JSON 파일 다운로드는 필수가 아닙니다.
3. **브라우저에서 Discord 로그인**을 누르고 자신의 계정으로 승인합니다. Discord PC 앱과 브라우저의 계정이 같은지 확인하세요.
4. 수신 상태와 전송 준비 상태를 확인하고 **완료**를 누릅니다. 웹후크를 넣지 않았다면 수신 전용으로 사용합니다.
5. 게임을 실행한 뒤 설정의 **실행 중인 앱 및 단축키**에서 해당 게임을 선택하고 **저장**합니다. 목록에 없으면 **목록 새로고침**을 누릅니다.
6. `Alt+Tab`으로 Sideglow를 선택해 상단의 채팅 **ON**을 확인한 뒤 게임으로 돌아갑니다. 기본 `Enter`로 메시지 입력을 시작할 수 있습니다.

**친구마다 Discord Developer Portal에서 앱이나 봇을 새로 만들 필요는 없습니다.** 일부 앱은 운영자의 App Testers 초대와 친구의 수락이 필요할 수 있습니다. 연결 코드에는 로그인 정보가 들어 있지 않으므로 각자 자신의 Discord 계정으로 승인해야 합니다.

## 내가 처음 연결을 준비하는 경우

운영자 한 명이 사용할 Discord 애플리케이션과 채널을 준비합니다. Sideglow의 **설정 → 처음 연결 / 로그인… → 내가 처음 준비하기**에서 순서대로 진행하세요.

1. Discord 애플리케이션을 준비하고 앱 ID와 로그인 복귀 주소를 설정합니다.
2. 사용할 채널에서 **채팅 수신이 실제로 되는지 먼저 확인**합니다.
3. 수신이 확인되면 같은 채널의 전송용 웹후크를 준비합니다.
4. **설정 → 연결 공유 코드… → 현재 설정 코드 복사**로 친구에게 전달합니다.

로그인 복귀 주소는 브라우저의 **Discord Developer Portal → 해당 앱 → OAuth2 → Redirects**에 등록합니다.

```text
http://127.0.0.1:43821/callback
```

이 주소는 로그인 승인을 마친 브라우저가 이 PC의 프로그램으로 돌아오기 위한 주소입니다. Sideglow의 채널 링크 입력란에 넣는 주소가 아닙니다. Public Client 설정, 앱 권한, 테스터 초대와 오류별 확인 방법은 [화면별 연결 안내](docs/SETUP.md)를 따르세요.

기본 직접 연결 방식에는 별도의 중계 서버나 번역 봇 호스팅이 필요하지 않습니다. Sideglow를 사용하는 동안 Discord PC 앱은 함께 실행해 두어야 합니다.

## 기본 조작

| 조작 | 동작 |
|---|---|
| 지정한 게임에서 `Enter` | 채팅 입력 시작. 다른 단축키로 변경 가능 |
| 입력 중 `Enter` | 작성한 메시지 전송. 빈칸이나 공백뿐이면 입력창 닫기 |
| 입력 중 `Esc` | 전송을 취소하고 게임으로 복귀. 작성 중인 내용은 유지 |
| `Alt+Tab`으로 Sideglow 선택 | 이동·크기 조절·탭 전환·설정을 위한 관리 화면 |
| 관리 화면의 오른쪽 스크롤바 | 이전 대화 확인 |
| 입력 중 마우스 휠 / `Page Up` / `Page Down` | 이전 대화 확인 |
| 상단 채팅 `ON/OFF` | 게임 위 표시와 입력 단축키 켜기·끄기 |
| 상단 번역 `ON/OFF` | 이 PC에서 현재 채널의 공용 AI 번역 실행 켜기·끄기 |

입력 중에는 키보드 포커스가 채팅창으로 이동합니다. 전송·닫기 후에는 `Enter` 또는 `Esc`를 뗀 뒤 게임으로 복귀하도록 처리합니다. 단축키 충돌이 있으면 설정에서 다른 키나 조합을 지정하세요.

## AI 번역 사용하기

일본어를 `arigatou`처럼 알파벳으로 입력하는 사용자는 기본 **설정 → 내 메시지의 로마자 일본어 판별 → 저장**을 선택하세요. 다른 사용자는 해제한 채 사용합니다. 이 선택은 앞으로 자신이 보내는 메시지에만 적용됩니다. 송신자와 번역 담당 PC 모두 **0.5.0-preview.7 이상**이어야 하며, 원래의 일본어 문자나 한국어를 번역하는 기능은 체크 여부와 관계없이 유지됩니다.

**채널마다 번역을 담당할 사람 한 명만 설정하면 됩니다.** 번역 담당자의 Sideglow와 Discord PC 앱이 실행 중이고, 번역할 채널 탭이 선택되어 있어야 합니다.

1. 담당자가 **설정 → AI 번역 설정… → API 제공사**에서 사용할 제공사를 고릅니다. **OpenAI 호환 서비스**는 **API 기본 주소**에 해당 서비스의 HTTPS 기본 주소를 넣습니다. 나머지 세 제공사의 공식 주소는 고정되어 있습니다.
2. **번역 API 키 · 이 Windows 계정에 보호 저장**에 자신의 키를 입력하고 **모델 ID · 직접 입력 가능**, 언어 A/B를 지정합니다. 타사 모델 ID는 직접 입력하며 OpenAI 모델 프리셋과 Fast는 OpenAI를 선택했을 때만 사용합니다.
3. **이 PC에서 공용 번역 실행**을 켜고, AI 설정의 **확인**과 기본 설정의 **저장**을 마칩니다.
4. 다른 사용자는 공용 번역 실행을 꺼 두고 **받은 AI 번역 표시**를 켭니다.
5. 새 메시지를 보내 원문 아래에 번역이 표시되는지 확인합니다.

한 PC에는 번역용 제공사·주소·키·모델 설정을 한 개만 저장하며 모든 채널 탭이 함께 사용합니다. **제공사나 API 기본 주소를 바꾸면 그 연결에 사용할 키를 새로 입력**해야 합니다. 같은 제공사·주소에서 모델만 바꿀 때는 키 입력란을 비워 두면 기존 키를 유지합니다. 지원하는 인증 방식과 모델 조건은 [API 제공사 설정](docs/API-PROVIDERS.md)을 확인하세요.

일반 사용자의 새 텍스트와 설정에 등록된 입력 웹후크의 메시지를 번역합니다. 결과는 같은 Discord 채널에 게시되므로 채널 구성원도 볼 수 있습니다. 과거 기록이나 비활성 탭의 메시지를 일괄 번역하지 않습니다.

API 사용량과 비용은 담당자가 입력한 키의 제공사 계정·프로젝트에 적용됩니다. 프로그램의 라이선스와 외부 API의 이용료는 별개입니다. 번역 담당자를 여러 명 켜면 중복 요청과 비용이 발생할 수 있으므로 한 명으로 정해 주세요.

번역 담당 기능은 기본으로 꺼져 있습니다. 꺼 둔 PC에서는 번역 작업자와 번역 API 통신 세션을 만들지 않습니다. 번역 속도는 선택한 모델, 메시지 길이, 네트워크와 서비스 상태에 따라 달라집니다. **설정 → 최근 번역 시간…**에서 대기열·API·Discord 게시 시간을 확인할 수 있습니다.

모델 선택과 상세 설정은 [AI 번역 안내](docs/AI-TRANSLATION.md)를 참고하세요.

## 채널과 화면 설정

`Alt+Tab` 관리 화면의 **+** 또는 **설정 → 채널 탭 → 추가…**에서 다른 채널을 추가합니다. 채널 주소나 웹후크만 바꾸려면 **채널·웹후크 수정…**을 사용하세요. 저장한 탭 중 현재 선택한 하나만 실시간으로 수신·번역합니다.

글꼴·색상·투명도·간격은 설정 창을 열어 둔 채 채팅창에서 미리 볼 수 있습니다. **번역문 별도 스타일**을 켜면 원문과 번역문의 크기·색상을 다르게 지정합니다. **저장**하면 유지하고 **취소·닫기**하면 저장 전 모양으로 돌아갑니다.

화면 언어는 **프로그램 언어 / UI language**에서 고릅니다. 화면 언어와 채팅 번역의 언어 A/B는 별도 설정입니다. 문구 수정과 언어 추가 방법은 [UI 언어 파일 안내](docs/LOCALIZATION.md)에 있습니다.

## 연결 정보와 개인정보

- 메시지는 개인 Discord 계정 대신 **웹후크 명의**로 전송됩니다. 기존 번역 봇이 웹후크 메시지를 무시하면 그 봇에서는 번역되지 않을 수 있습니다.
- **웹후크 URL과 이를 포함한 연결 코드는 전송 권한이 있는 정보입니다.** 신뢰하는 사람에게만 전달하고 공개 저장소·README·Issue에 올리지 마세요. 연결 코드는 복원 가능한 인코딩이며 암호화가 아닙니다.
- 연결 공유 코드에는 앱 ID·채널·선택적인 웹후크가 들어갑니다. 자신의 Discord 로그인 토큰이나 번역 API 키는 포함하지 않습니다.
- AI 번역을 실행하면 대상 메시지의 내용, 선택한 언어와 게임 용어가 선택한 API 제공사로 전송됩니다. 호환 서비스를 선택하면 직접 입력한 주소가 수신 대상입니다. 결과는 설정한 Discord 채널에 게시됩니다.
- 저장된 API 키와 민감한 연결 정보는 Windows 사용자 계정에 연결된 보호 기능을 사용합니다. 다른 PC나 Windows 계정으로 옮길 때 다시 입력하거나 로그인해야 할 수 있습니다.

연결 코드의 범위와 취급 방법은 [연결 코드 안내](docs/CONNECTION-CODE.md)를 참고하세요.

## 현재 지원 범위

- Windows 10/11 x64와 창 모드·테두리 없는 창 모드를 대상으로 합니다.
- 게임 프로세스에 DLL을 삽입하지 않으며, 단축키와 별도의 Windows 창을 사용합니다.
- 독점 전체 화면, 관리자 권한으로 실행한 게임, 안티치트와 입력기 환경에 따라 표시·입력·포커스 복귀가 제한될 수 있습니다.
- AI 번역 연동은 OpenAI Responses, OpenAI 호환 Chat Completions, Anthropic Messages, Gemini GenerateContent를 지원합니다. 호환 서비스는 Bearer 인증과 JSON mode 등을 지원해야 하며 자세한 조건은 [API 제공사 설정](docs/API-PROVIDERS.md)에 있습니다. 게임 자체의 채팅 수집, OCR, 음성 인식, 이미지 번역은 지원하지 않습니다.
- 타사 API 연동은 요청·응답 fixture를 이용한 모의 테스트로 검증했습니다. 이번 작업에서는 실제 타사 키로 API를 호출하지 않았으며 서비스별 모델 접근·응답 품질·실제 속도를 검증한 것은 아닙니다.
- 현재는 미리보기 단계입니다. 모든 게임·Discord 계정의 연결이나 일정한 번역 속도를 보장하지 않습니다. 자동 검사·Windows 빌드와 실환경 검증의 범위는 [검증 기록](docs/VALIDATION.md)에 구분해 두었습니다.

## 소스에서 빌드하기

Windows 10/11 x64에서 Rust의 MSVC 도구 체인과 Visual Studio C++ Build Tools 및 Windows SDK가 필요합니다. 설치는 [Rust 공식 안내](https://www.rust-lang.org/tools/install)를 참고하세요.

저장소를 내려받은 뒤 프로젝트 폴더에서 PowerShell로 실행합니다.

```powershell
rustup target add x86_64-pc-windows-msvc
.\scripts\build.ps1
```

빌드가 끝나면 `dist/sideglow.exe`와 `dist/locales/`가 생성됩니다. 두 항목을 함께 두고 실행하세요. 컴파일된 배포본을 받는 일반 사용자는 Rust나 C++ 빌드 도구를 설치할 필요가 없습니다.

실행 파일을 재배포할 때는 해당 빌드에 대응하는 소스와 라이선스·외부 구성 요소 고지도 제공해야 합니다. 빌드 스크립트의 `dist` 출력만으로 전체 배포 ZIP이 완성되는 것은 아닙니다. 자세한 내용은 [라이선스 안내](docs/LICENSING.md)를 확인하세요.
