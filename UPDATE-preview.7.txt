Sideglow 0.5.0-preview.7 업데이트

저장 경로 변경을 포함한 미배포 사본입니다. 버전 번호는 그대로이며 새 공식 버전 발행이 아닙니다.

1. 실행 중인 Sideglow와 이전 실행 파일을 모두 완전히 종료합니다.
2. Windows 배포 ZIP은 기존 sideglow.exe가 있는 프로그램 폴더에, 변경 소스 ZIP은 Cargo.toml이 있는 프로젝트 폴더에 복사합니다.
3. 프로그램 폴더의 같은 이름 파일은 덮어쓰고 src, locales, docs 등의 폴더는 병합합니다.
4. 아래 저장 폴더 준비를 마친 뒤 sideglow.exe를 다시 실행합니다. 변경 소스 ZIP만 적용한 경우에는 먼저 다시 빌드한 실행 파일을 사용합니다.

기본 저장 폴더는 %LOCALAPPDATA%\Sideglow\입니다.
기존 설정 폴더의 자동 탐색·이전은 없습니다.
기존 설정·로그인을 유지하려면 같은 PC·같은 Windows 계정에서 앱을 완전히 종료한 상태로 준비합니다.
%LOCALAPPDATA% 안에 Sideglow 폴더가 이미 있으면 두 폴더를 별도로 보관하고 어느 설정을 쓸지 먼저 확인합니다. 설정 폴더끼리 덮어쓰거나 병합하지 않습니다.
사용하지 않을 폴더는 별도 이름으로 보관하고, 사용할 기존 설정 폴더 이름을 Sideglow로 바꿉니다. settings.json과 rpc-session.bin을 포함한 폴더 전체를 유지합니다.
새 설정으로 초기화하려면 앱을 완전히 종료하고 Sideglow 저장 폴더가 있다면 별도 이름으로 보관한 뒤 실행합니다. 기존 설정 폴더는 자동으로 읽지 않습니다.
초기화하면 Discord 재로그인·연결 설정·API 키 입력을 다시 해야 합니다. 폴더 이름 변경은 만료된 로그인이나 손상된 파일의 복구를 보장하지 않습니다.
자세한 절차는 docs/SETUP.md의 [저장 폴더 변경과 초기화]를 참고하세요.

웹후크 이름 접두부는 오버레이에서 숨기고 실제 닉네임은 보존합니다.
메시지 시각은 Windows 현지 시간대로 표시합니다.

일본어를 알파벳으로 쓰는 사용자는 기본 설정에서
[내 메시지의 로마자 일본어 판별]을 켜고 저장합니다. 기본값은 꺼짐입니다.
옵션을 쓰는 송신자와 공용 번역을 실행하는 PC가 모두 preview.7이어야 합니다.
Node 중계를 쓰면 relay 소스도 갱신한 뒤 중계를 다시 시작합니다.

다른 번역 API는 기본 설정의 [AI 번역 설정]에서
[API 제공사], [API 기본 주소], [API 키], [번역 모델]을 지정한 뒤
[확인]하고 기본 설정에서 [저장]합니다.
API 제공사/주소가 바뀌면 해당 목적지의 키를 새로 입력합니다.
한 번에 한 제공사 구성을 사용합니다. 자세한 조건은 docs/API-PROVIDERS.md를 참고하세요.

이 압축파일에는 사용자 설정, 로그인 정보 또는 실제 API 키가 없습니다.
앞서 삭제한 프로젝트 자체 MIT 고지 파일은 다시 넣지 않습니다.
자체 소스의 MPL 2.0 및 실제 외부 구성 요소 고지는 유지합니다.

전체 배포본에는 수정 가능한 소스도 함께 들어 있습니다.
GitHub-source.zip은 실행 파일이 없는 별도 소스 배포본입니다.
검증 범위와 실행 파일 해시는 docs/VALIDATION.md, docs/BUILD-INFO.json에 있습니다.
