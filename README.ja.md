# Sideglow

[한국어](README.md) | **日本語** | [English](README.en.md)

**ゲーム画面に重ねて使うDiscordチャット・翻訳オーバーレイ**

Sideglowは、Discordチャンネルの会話をゲーム画面に重ねて表示し、ショートカットキーでメッセージを送信できるWindows用チャットウィンドウです。必要に応じてAI翻訳を有効にすると、異なる言語で書かれた会話と翻訳文を一緒に確認できます。

RustとWindowsのネイティブUIで実装し、小さなウィンドウと必要な機能に重点を置いています。DiscordのPCアプリと併用します。ゲーム内チャットの読み取りや、OCRによる画面の翻訳には対応していません。

> **[Sideglow](https://github.com/PN-7/sideglow/releases)**

## 始める前に

**DiscordのPCクライアントをインストールし、使用するアカウントでログインした状態で起動しておく必要があります。** SideglowはこのPCアプリを通じてチャンネルのメッセージを受信します。ブラウザー版やモバイル版のDiscordだけでは使用できません。

| 準備するもの | 必要な内容 |
|---|---|
| OS | インターネットに接続されたWindows 10/11 64ビットPC |
| DiscordのPCアプリ | インストールとログインを済ませ、起動しておいてください。[Discordをダウンロード](https://discord.com/download) |
| Discordアカウント | 使用するサーバーとテキストチャンネルにアクセスできる必要があります。ブラウザーでの認証とPCアプリで同じアカウントを使ってください。 |
| 接続情報 | 管理者や友人から受け取った接続コード、またはDiscordアプリケーションIDとチャンネルリンク |
| メッセージ送信 | 同じチャンネルのWebhook URLが別途必要です。Webhookがない場合は受信専用で使用します。 |
| ゲームの画面モード | ウィンドウモードまたはボーダーレスウィンドウモードを前提に設計しています。 |
| AI翻訳 — 任意 | 翻訳を担当する1人だけ、選択したAPIプロバイダーのキーが必要です。OpenAI、OpenAI互換サービス、Anthropic、Geminiに対応しており、結果を受け取るだけの人にはキーは必要ありません。 |

**現在の接続方式には、Discord側のアプリ権限による制限があります。** チャットの受信に使うRPC権限は、アプリの承認条件に左右されます。Discordアプリを作成したり、テスター招待を承諾したりしただけで、すべてのアカウントの接続が保証されるわけではありません。初めて準備する場合は、友人に配布する前に、自分と友人のアカウントで実際に受信できることを確認してください。詳しい手順は[Discord接続ガイド](docs/SETUP.md)にあります。権限の範囲は[Discord公式OAuth2ドキュメント](https://docs.discord.com/developers/topics/oauth2)を参照してください。

## 主な機能

- **ゲーム画面にチャットを表示:** Discordチャンネルの原文と翻訳の返信を一緒に確認できます。送信者はWebhookの接頭辞を除いたニックネームで、メッセージの時刻はWindowsのローカル時刻で表示します。
- **ショートカットキーで入力:** 指定したゲームで、初期設定では`Enter`を押すと入力欄が開きます。ショートカットキーは設定で変更できます。
- **クリック透過とウィンドウの編集:** 通常はマウスクリックをゲーム側に通します。`Alt+Tab`でSideglowを選択すると、ウィンドウを移動したり、端をドラッグしてサイズを変更したりできます。
- **チャンネルタブ:** 最大8チャンネルを保存できます。リアルタイムで受信・翻訳するのは、選択中の1つのタブだけです。
- **読みやすさを調整できる画面設定:** システムフォント、文字サイズ、本文・発言者・翻訳文の色、文字間隔・行間、文字の縁取り、背景色・不透明度を調整できます。外観の変更は保存前にもプレビューできます。
- **古い会話を非表示に:** 設定した時間が経過した会話を、画面から順に非表示にします。Discordチャンネル内の実際のメッセージは残ります。
- **任意のAI翻訳:** OpenAI、OpenAI互換サービス、Anthropic、Geminiのいずれかを選び、1人のAPIキーでチャンネルの新しい会話を翻訳します。全員が翻訳結果を受け取れ、管理画面で翻訳のON/OFFを切り替えられます。
- **個人用のローマ字日本語オプション:** 日本語をアルファベットで入力する人だけ、設定の**自分のメッセージのローマ字日本語を判別**にチェックを入れて保存してください。初期設定はOFFで、翻訳を担当しない人も選択できます。
- **表示言語:** 韓国語・日本語・英語に対応しています。UIの文言は外部JSONファイルで編集できます。

## ダウンロードと起動

**現在、このリポジトリではソースを公開しています。GitHub Releasesでの実行ファイルの配布は、まだ公開していません。** GitHubの**Code → Download ZIP**でダウンロードされるのはソースのZIPです。自分で実行ファイルを作る場合は、下記の[ソースからビルドする](#ソースからビルドする)を参照してください。

Windows x64用の実行ファイルが含まれる配布ZIPを受け取った場合:

1. Windows x64用Sideglowの配布ZIPを用意します。
2. ZIPを展開し、実行ファイルと`locales`フォルダーを同じフォルダーに置きます。
3. DiscordのPCアプリにログインしてから、実行ファイルを開きます。実行ファイル名は`sideglow.exe`です。
4. 以下の接続手順を進めます。更新時は、既存のプログラムを完全に終了してから新しいバージョンを起動してください。

実行ファイルを使う場合、RustやNode.jsを別途インストールする必要はありません。`start-demo.cmd`はサンプル画面を確認するためのものです。実際のDiscord接続には通常の実行ファイルを使ってください。

## 友人から接続情報を受け取った場合

1. **設定 → 初回接続・ログイン… → 友人から受け取ったコード・リンクで接続**を開きます。
2. **接続コードを貼り付け… → コードを貼り付け → 設定に入力**で、受け取ったコードを適用します。アプリID・チャンネルリンク・Webhook URLを直接入力しても構いません。JSONファイルのダウンロードは必須ではありません。
3. **ブラウザーでDiscordにログイン**を押し、自分のアカウントで認証を許可します。DiscordのPCアプリとブラウザーで同じアカウントを使用していることを確認してください。
4. 受信状態と送信の準備状態を確認し、**完了**を押します。Webhookを入力していない場合は受信専用になります。
5. ゲームを起動し、設定の**実行中のアプリとショートカット**でそのゲームを選んで**保存**します。一覧にない場合は**一覧を更新**を押してください。
6. `Alt+Tab`でSideglowを選択し、上部のチャットが**ON**になっていることを確認してからゲームに戻ります。初期設定では`Enter`でメッセージ入力を開始できます。

**友人がそれぞれDiscord Developer Portalで新しいアプリやBotを作る必要はありません。** アプリによっては、管理者からのApp Testers招待と、友人側での承諾が必要になる場合があります。接続コードにログイン情報は含まれないため、各自のDiscordアカウントで認証を許可してください。

## 自分が初めて接続を準備する場合

管理者1人が、使用するDiscordアプリケーションとチャンネルを準備します。Sideglowの**設定 → 初回接続・ログイン… → 自分が最初に準備する**から順に進めてください。

1. Discordアプリケーションを用意し、アプリIDとログイン後のリダイレクト先を設定します。
2. 使用するチャンネルで、**実際にチャットを受信できるかを先に確認**します。
3. 受信できたら、同じチャンネルに送信用Webhookを用意します。
4. **設定 → 接続コード… → 現在の接続コードをコピー**で、友人に共有します。

ログイン後のリダイレクト先は、ブラウザーの**Discord Developer Portal → 対象のアプリ → OAuth2 → Redirects**に登録します。

```text
http://127.0.0.1:43821/callback
```

このアドレスは、認証を許可したブラウザーから、このPC上のプログラムへ戻るためのものです。Sideglowのチャンネルリンク欄に入力するアドレスではありません。Public Client設定、アプリ権限、テスター招待、エラーごとの確認方法は[画面別の接続ガイド](docs/SETUP.md)を参照してください。

標準の直接接続方式では、別途中継サーバーや翻訳Botのホスティングを用意する必要はありません。Sideglowの使用中は、DiscordのPCアプリも起動しておいてください。

## 基本操作

| 操作 | 動作 |
|---|---|
| 指定したゲームで`Enter` | チャット入力を開始。別のショートカットキーに変更可能 |
| 入力中に`Enter` | 入力したメッセージを送信。空欄または空白だけの場合は入力欄を閉じる |
| 入力中に`Esc` | 送信を取りやめ、ゲームに戻る。入力中の内容は保持 |
| `Alt+Tab`でSideglowを選択 | 移動・サイズ変更・タブ切り替え・設定を行う管理画面 |
| 管理画面の右側のスクロールバー | 過去の会話を確認 |
| 入力中にマウスホイール / `Page Up` / `Page Down` | 過去の会話を確認 |
| 上部のチャット`ON/OFF` | ゲーム画面への表示と入力ショートカットのON/OFF |
| 上部の翻訳`ON/OFF` | このPCで、現在のチャンネルの共有AI翻訳を開始・停止 |

入力中は、キーボードフォーカスがチャットウィンドウに移ります。送信・終了後は、`Enter`または`Esc`を離してからゲームに戻るように処理しています。ショートカットキーが競合する場合は、設定で別のキーやキーの組み合わせを指定してください。

## AI翻訳を使う

日本語を`arigatou`のようにアルファベットで入力する人は、基本設定の**設定 → 自分のメッセージのローマ字日本語を判別 → 保存**を選択してください。それ以外の人はOFFのまま使用します。この設定は、これから自分が送信するメッセージだけに適用されます。送信者と翻訳担当PCの両方で、**0.5.0-preview.7以上**が必要です。通常の日本語表記や韓国語を翻訳する機能は、チェックの有無にかかわらず利用できます。

**チャンネルごとに、翻訳を担当する人が1人だけ設定すれば利用できます。** 翻訳担当者のSideglowとDiscordのPCアプリが起動しており、翻訳するチャンネルのタブが選択されている必要があります。

1. 担当者が**設定 → AI翻訳設定… → APIプロバイダー**で、使用するプロバイダーを選びます。**OpenAI互換サービス**の場合は、**APIベースURL**にそのサービスのHTTPSベースURLを入力します。それ以外の3つのプロバイダーは公式アドレスが固定されています。
2. **翻訳APIキー · このWindowsアカウント用に保護して保存**に自分のキーを入力し、**モデルID · 直接入力可能**と言語A/Bを指定します。他社のモデルIDは直接入力してください。OpenAIモデルのプリセットとFastは、OpenAIを選んだ場合だけ使用できます。
3. **このPCで共有翻訳を実行**をONにし、AI翻訳設定で**OK**、基本設定で**保存**を押します。
4. それ以外の人は共有翻訳の実行をOFFにし、**受信したAI翻訳を表示**をONにします。
5. 新しいメッセージを送り、原文の下に翻訳が表示されることを確認します。

1台のPCには翻訳用のプロバイダー・アドレス・キー・モデル設定を1つだけ保存し、すべてのチャンネルタブで共有します。**プロバイダーやAPIベースURLを変更した場合は、その接続で使用するキーを新しく入力**する必要があります。同じプロバイダー・アドレスのままモデルだけを変更する場合は、キー入力欄を空欄にすると既存のキーを保持します。対応する認証方式とモデルの条件は[APIプロバイダー設定](docs/API-PROVIDERS.md)を参照してください。

一般ユーザーの新しいテキストと、設定に登録した入力用Webhookからのメッセージを翻訳します。結果は同じDiscordチャンネルに投稿されるため、チャンネルのメンバーも見ることができます。過去の履歴や、選択していないタブのメッセージをまとめて翻訳することはありません。

API使用量と料金は、担当者が入力したキーのプロバイダーアカウント・プロジェクトに適用されます。プログラムのライセンスと外部APIの利用料金は別のものです。複数人が翻訳担当機能をONにすると、リクエストや料金が重複する場合があるため、担当は1人に決めてください。

翻訳担当機能は初期設定でOFFです。OFFのPCでは、翻訳ワーカーや翻訳APIの通信セッションを作成しません。翻訳速度は、選択したモデル、メッセージの長さ、ネットワーク、サービスの状態によって変わります。**設定 → 直近の翻訳時間…**で、キュー・API・Discordへの投稿にかかった時間を確認できます。

モデルの選択と詳細な設定については、[AI翻訳ガイド](docs/AI-TRANSLATION.md)を参照してください。

## チャンネルと画面の設定

`Alt+Tab`の管理画面にある**+**、または**設定 → チャンネルタブ → 追加…**から、別のチャンネルを追加できます。チャンネルのアドレスやWebhookだけを変更する場合は、**チャンネル・Webhookを編集…**を使ってください。保存したタブのうち、リアルタイムで受信・翻訳するのは現在選択している1つだけです。

フォント・色・透明度・間隔は、設定ウィンドウを開いたままチャットウィンドウでプレビューできます。**翻訳文を別スタイルにする**をONにすると、原文と翻訳文で異なるサイズ・色を指定できます。**保存**すると変更を保持し、**キャンセル・閉じる**と保存前の外観に戻ります。

表示言語は**表示言語 / UI language**で選びます。表示言語と、チャット翻訳の言語A/Bは別々の設定です。文言の編集や言語の追加方法は、[UI言語ファイルガイド](docs/LOCALIZATION.md)を参照してください。

## 接続情報とプライバシー

- メッセージは個人のDiscordアカウントではなく、**Webhook名義**で送信されます。既存の翻訳BotがWebhookメッセージを無視する場合、そのBotでは翻訳されないことがあります。
- **Webhook URLと、それを含む接続コードは、メッセージを送信できる権限を持つ情報です。** 信頼できる人にだけ共有し、公開リポジトリ・README・Issueには載せないでください。接続コードは元に戻せるエンコーディングであり、暗号化ではありません。
- 接続コードには、アプリID・チャンネル・任意のWebhookが含まれます。自分のDiscordログイントークンや翻訳APIキーは含まれません。
- AI翻訳を実行すると、対象メッセージの内容、選択した言語、ゲーム用語が、選択したAPIプロバイダーに送信されます。互換サービスを選んだ場合は、直接入力したアドレスが送信先です。結果は設定したDiscordチャンネルに投稿されます。
- 保存されたAPIキーと機密性のある接続情報には、Windowsユーザーアカウントにひもづく保護機能を使用します。別のPCやWindowsアカウントに移す場合は、再入力や再ログインが必要になることがあります。

接続コードに含まれる情報と取り扱いについては、[接続コードガイド](docs/CONNECTION-CODE.md)を参照してください。

## 現在の対応範囲

- Windows 10/11 x64と、ウィンドウモード・ボーダーレスウィンドウモードを対象にしています。
- ゲームプロセスにDLLを挿入せず、ショートカットキーと独立したWindowsウィンドウを使用します。
- 排他的フルスクリーン、管理者権限で起動したゲーム、アンチチートやIMEの環境によっては、表示・入力・フォーカスの復帰に制約が生じる場合があります。
- AI翻訳連携は、OpenAI Responses、OpenAI互換Chat Completions、Anthropic Messages、Gemini GenerateContentに対応しています。互換サービスはBearer認証やJSON modeなどに対応している必要があります。詳しい条件は[APIプロバイダー設定](docs/API-PROVIDERS.md)を参照してください。ゲーム内チャットの取得、OCR、音声認識、画像翻訳には対応していません。
- 他社APIとの連携は、リクエスト・レスポンスのfixtureを使ったモックテストで検証しました。今回の作業では実際の他社APIキーでAPIを呼び出しておらず、サービスごとのモデルへのアクセス、応答品質、実際の速度を検証したものではありません。
- 現在はプレビュー段階です。すべてのゲーム・Discordアカウントでの接続や、一定の翻訳速度を保証するものではありません。自動チェック・Windowsビルドと、実環境での検証の範囲は[検証記録](docs/VALIDATION.md)で区別しています。

## ソースからビルドする

Windows 10/11 x64で、RustのMSVCツールチェーン、Visual Studio C++ Build Tools、Windows SDKが必要です。インストール方法は[Rust公式ガイド](https://www.rust-lang.org/tools/install)を参照してください。

リポジトリをダウンロードした後、プロジェクトフォルダーでPowerShellを使って実行します。

```powershell
rustup target add x86_64-pc-windows-msvc
.\scripts\build.ps1
```

ビルドが完了すると、`dist/sideglow.exe`と`dist/locales/`が生成されます。両方を一緒に置いて実行してください。ビルド済みの配布物を受け取る一般ユーザーは、RustやC++のビルドツールをインストールする必要はありません。

実行ファイルを再配布する場合は、そのビルドに対応するソースと、ライセンス・外部コンポーネントの通知も提供する必要があります。ビルドスクリプトの`dist`出力だけで、配布ZIP全体が完成するわけではありません。詳しくは[ライセンスガイド](docs/LICENSING.md)を確認してください。
