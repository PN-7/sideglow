# 화면 언어 파일 편집 — 0.5.0-preview.7

Sideglow의 버튼·설정·안내 문구는 실행 파일 옆의 **`locales` 폴더**에서 번역합니다. 프로그램 화면 언어를 바꾸는 기능이며, 채팅을 어떤 언어로 번역할지 정하는 **AI 번역의 언어 A/B와는 별개**입니다.

## 처음 사용하는 경우

1. 배포 압축을 풀어 `sideglow.exe`와 `locales` 폴더를 같은 폴더에 둡니다. 폴더 안에는 `ko.json`, `ja.json`, `en.json`이 있습니다.
2. Sideglow를 실행하고 **Alt+Tab → 설정 → 프로그램 언어 / UI language**를 엽니다.
3. **한국어**, **日本語**, **English** 중 하나를 고르고 **저장**합니다. 오버레이에 적용되고 설정 창은 닫힙니다. 다시 열면 설정도 새 언어로 표시합니다.

이전에 저장한 설정에는 화면 언어가 없으므로 한국어로 시작합니다. 언어를 선택한 뒤 **취소·닫기**를 누르면 이전 선택을 유지합니다. 채팅 번역 A/B, API 키, 모델, 채널과 단축키 설정은 그대로입니다.

Windows가 제공하는 글꼴·색상·파일 선택 대화상자의 시스템 버튼·항목은 Windows 표시 언어를 따릅니다. 사용자 채팅과 직접 정한 탭 이름도 화면 언어 선택으로 번역하지 않습니다.

## 기존 번역을 고치기

편집하려는 파일을 UTF-8을 지원하는 텍스트 편집기로 엽니다.

| 파일 | 화면 언어 |
|---|---|
| `locales/ko.json` | 한국어 |
| `locales/ja.json` | 日本語 |
| `locales/en.json` | English |

파일은 다음 구조입니다. 아래는 형식 설명을 위한 일부 문구 예시이며, 전체 파일을 이 예시로 덮어쓸 필요는 없습니다.

```json
{
  "locale": "en",
  "name": "English",
  "messages": {
    "common.save": "&Save"
  }
}
```

- **`locale`**: 확장자를 뺀 파일 이름입니다. `en.json`이면 `en`입니다.
- **`name`**: 언어 팩을 설명하는 이름입니다.
- **`messages`의 왼쪽 키**: 프로그램이 문구를 찾는 식별자입니다. 그대로 두세요. 파일·기능 이름과 짧은 식별값을 포함한 키도 정상입니다.
- **`messages`의 오른쪽 값**: 번역할 문구입니다. 이 값을 편집합니다.

파일 저장 후 다음 중 하나로 적용합니다.

- Sideglow를 완전히 종료하고 다시 실행합니다.
- 설정에서 다른 화면 언어를 선택하여 저장한 뒤, 수정한 언어를 다시 선택하여 저장합니다.

언어 파일을 계속 감시하거나 주기적으로 다시 읽지는 않습니다. 설정에서 언어만 선택하고 취소한 경우에는 변경이 적용되지 않습니다.

## 번역할 때 유지할 항목

### 자리표시자

`{arg0}`, `{arg1}`, `{code}`, `{name}`처럼 중괄호로 둘러싸인 항목은 프로그램이 숫자나 이름을 넣는 자리입니다. **원문에 있는 자리표시자를 같은 이름으로 모두 유지**해야 합니다. 문법에 맞게 문장 안의 위치를 옮기는 것은 가능합니다.

예를 들어 원문에 `{code}`가 있으면 번역문에도 `{code}`를 넣습니다. `{코드}`로 번역하거나 이름을 바꾸지 않습니다. 자리표시자를 없애거나 새로 만드는 것도 피하세요. 원문에 중괄호를 표시하기 위한 별도 표기가 있다면 그대로 유지합니다.

### 줄바꿈·따옴표·역슬래시

JSON 문자열 안에서 줄바꿈은 `\n` 또는 `\r\n`, 따옴표는 `\"`, 역슬래시는 `\\`로 적습니다. 긴 안내문은 기존 줄바꿈의 의미를 유지하며 자연스럽게 번역하세요. JSON은 문자열 안에 실제 줄바꿈을 그대로 넣을 수 없고, 항목 사이의 쉼표도 필요합니다.

한글·일본어·영어 등은 UTF-8 문자 그대로 작성할 수 있습니다. 모든 문자를 `\uXXXX`로 바꿀 필요는 없습니다. 파일 전체를 UTF-8로 저장하고, 같은 키를 중복해서 만들지 마세요.

### 키보드 단축 문자와 길이

일부 버튼의 `&`는 Windows 키보드 접근 문자를 나타냅니다. 예를 들어 `저장(&S)`는 영어에서 `&Save`, 일본어에서 `保存(&S)`처럼 쓸 수 있습니다. 같은 화면에서 접근 문자가 불필요하게 겹치지 않도록 정하세요. 글자 그대로의 `&` 표기가 필요한 경우에는 기존 표기를 확인합니다.

버튼은 간결하게 번역하고, 자세한 설명은 안내문에서 전달하세요. 언어마다 문구 길이가 다르므로 실제 화면에서 버튼 끝이 잘리지 않는지 확인하는 것이 좋습니다. 설치된 글꼴과 Windows 화면 배율에 따라서도 결과가 달라집니다. 영어·일본어 파일은 초기 번역이며, 자연스러운 표현이나 게임 용어는 직접 교정할 수 있습니다.

## 다른 언어 추가하기

1. 포함된 `ko.json` 또는 이미 읽기 쉬운 언어 파일을 복사합니다.
2. 예를 들어 프랑스어는 파일 이름을 **`fr.json`**, 파일 안의 `locale`을 **`fr`**, `name`을 **`Français`**로 바꿉니다.
3. `messages`의 키와 자리표시자를 유지하며 값만 번역합니다.
4. 실행 파일 옆 `locales` 폴더에 저장하고 설정을 다시 엽니다. 목록의 **`fr`**를 선택한 뒤 저장합니다.

목록을 만들 때 모든 언어 파일 본문을 읽지 않기 때문에, 사용자 추가 언어는 `name` 대신 `fr` 같은 **파일 식별자**로 표시합니다. 한국어·日本語·English는 알아보기 쉬운 고정 이름으로 표시합니다.

새 언어 파일을 추가하거나 기존 번역을 바꾸는 데 재컴파일은 필요하지 않습니다. 다만 프로그램에 없는 새로운 기능·문구 키를 JSON에 적는 것만으로 화면 항목이 생기지는 않습니다.

### 파일 식별자와 크기

| 항목 | 제한 |
|---|---|
| 파일 위치 | 실행 파일 디렉터리의 `locales` 폴더 |
| 확장자 | `.json` |
| 언어 식별자 | 2~32 ASCII 문자. 첫 글자는 영문, 나머지는 영문·숫자·`_`·`-` |
| 예시 | `fr`, `pt-BR`, `zh-Hant`, `custom2` |
| 사용할 수 없는 이름 | 경로·점·공백을 포함한 이름, Windows 장치 이름 `CON`, `PRN`, `AUX`, `NUL`, `COM1`~`COM9`, `LPT1`~`LPT9` |
| 파일 전체 | 최대 1 MiB |
| 문구 하나 | UTF-8 기준 최대 16 KiB |

파일의 `locale`은 확장자를 뺀 파일 식별자와 정확히 맞춥니다. 언어 파일에는 화면 문구만 넣습니다. Discord 링크, 웹후크 URL, API 키나 개인 설정을 복사할 필요가 없습니다.

## 파일이 없거나 잘못된 경우

기본 한국어 문구는 실행 파일에도 포함되어 있습니다. 번역이 빠진 항목이나 사용할 수 없는 번역문은 그 기본 문구로 표시합니다. 선택한 언어 파일 전체를 읽거나 검증할 수 없다면 한국어로 동작하며 안내합니다. 잘못된 파일 때문에 채팅 연결이나 저장된 개인 설정을 지우지는 않습니다.

언어 파일을 수정하다 화면에 한국어가 섞여 나오면 해당 키의 번역 누락·자리표시자·JSON 형식·길이부터 확인하세요. 파일이 삭제된 저장 언어도 설정 목록에 남겨 선택값을 확인할 수 있습니다. 기본 언어를 선택하여 저장한 뒤 파일을 고치고 다시 선택할 수 있습니다.

## 자원 사용과 검증 범위

시작하거나 화면 언어를 바꿀 때 **선택한 파일 하나만** 읽어 문구를 준비합니다. 설정 창에서 추가 언어를 찾을 때는 파일 이름만 확인합니다. 매번 화면을 그릴 때 JSON을 해석하지 않고, 감시 스레드·주기적인 파일 읽기·언어 번역용 네트워크 요청을 추가하지 않습니다.

문구와 조회 정보를 저장할 메모리는 사용합니다. 이 설명은 구현 구조에 대한 것이며, 실제 Windows CPU·RAM·게임 프레임의 차이를 측정한 결과는 아닙니다. 수행한 검사와 남은 실환경 확인은 [VALIDATION.md](VALIDATION.md)에 있습니다.

## Quick guide in English

Keep the `locales` folder beside `sideglow.exe`. Choose **UI language** in Settings and save. Reopen Settings to see the translated controls. The interface language is separate from the AI chat translation language pair.

To edit a translation, change values in `messages`, keep the keys and all `{placeholders}`, and save as UTF-8 JSON. Restart Sideglow, or save another UI language and then switch back, to reload the edited file. To add a language, copy a supplied catalog to a new valid filename such as `fr.json`, set `locale` to `fr`, translate the values, and reopen Settings. Custom languages appear by their file identifier. Missing or invalid translations fall back to Korean.
