# Sideglow 라이선스 적용 범위

## 현재 프로젝트

Sideglow 0.5.0-preview.7의 이번 공개본에 포함되는 프로젝트 자체 소스와 자체 리소스에는 **Mozilla Public License 2.0(MPL-2.0)**을 적용합니다. 원문은 루트 [LICENSE](../LICENSE), 적용 범위와 관련 고지는 [NOTICE](../NOTICE)에 있습니다.

Rust·JavaScript·PowerShell 등 주석을 넣을 수 있는 프로젝트 소스에는 SPDX 식별자를 표시합니다. JSON 언어 파일·설정 예시처럼 주석을 넣기 곤란한 자체 파일은 루트 NOTICE의 적용 범위에 포함합니다. 외부 라이브러리·런타임·원래의 라이선스 파일에는 이 표기를 덮어쓰지 않습니다.

MPL은 파일 단위로 적용됩니다. MPL 코드를 수정해 프로그램을 배포하면 해당 MPL 소스와 수정분을 받을 수 있는 방법을 수령자에게 제공해야 합니다. MPL 코드를 포함하지 않은 별도 파일은 다른 조건으로 배포할 수 있습니다. 판매를 금지하거나, 수정자가 원래 저장소에 반드시 PR을 제출하도록 하는 라이선스는 아닙니다. [Mozilla 공식 FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/)

## 공개 전 제공본과 라이선스 이력

이 프로젝트의 공개 전 개발용 패키지에는 프로젝트 자체에 MIT 표기가 들어 있었습니다. 이 사실은 개발 이력이며, 이번 공개본의 자체 코드에 MIT를 함께 적용한다는 뜻이 아닙니다.

이번 공개본은 자체 소스와 자체 리소스에 MPL 2.0을 적용하며, 이전 프로젝트 자체의 MIT 고지 원문은 배포 구성에 포함하지 않습니다. 외부 구성 요소의 라이선스·저작권 고지는 각각의 원래 조건에 따라 보존합니다.

개별 제공된 이전 사본에 관하여 유효하게 부여된 이용 권한은 이번 공개본의 라이선스 변경으로 소급하여 변경하거나 취소하지 않습니다. 이전 자체 MIT 고지 원문을 이번 공개본에 동봉하지 않는다는 사실로 그 권리가 없어지는 것은 아닙니다.

## 외부 구성 요소

외부 Rust 패키지와 표준 라이브러리·MinGW/GCC 런타임에는 각각의 원래 라이선스가 적용됩니다. 목록은 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md), 원문은 `third_party_licenses/`에 있습니다. `unicode-ident`의 Unicode-3.0 추가 고지도 유지합니다.

허용적 라이선스의 코드를 MPL 프로젝트와 함께 사용할 수 있다는 것과, 출처가 불명확한 복사 코드의 사용 권한이 생긴다는 것은 별개입니다. 라이선스 선택만으로 누락된 허가를 대신할 수 없습니다. [Mozilla 코드 도입 지침](https://www.mozilla.org/en-US/MPL/2.0/permissive-code-into-mpl/)

## 실행 파일을 배포할 때

공식 Windows 배포 ZIP에는 실행 파일과 대응하는 `src/`, `build.rs`, `Cargo.toml`, `Cargo.lock`, `assets/`, `locales/`, 빌드 스크립트 및 라이선스 고지를 함께 포함합니다. 소스를 ZIP에서 바로 얻을 수 있습니다. GitHub 저장소에는 소스와 고지를 올리고, 실행 파일과 배포 ZIP은 별도로 배포합니다.

직접 빌드한 결과를 재배포할 때도 그 빌드에 사용한 수정 가능한 소스와 필요한 고지를 함께 제공하거나, 해당 버전의 소스를 받을 수 있는 유효한 주소를 안내해야 합니다. 루트 LICENSE·NOTICE·외부 구성 요소 고지를 유지하세요. [MPL 2.0 §3.2](https://www.mozilla.org/en-US/MPL/2.0/)

## 출처 점검의 범위

[출처 점검 기록](PROVENANCE.md)은 확인한 의존성·고지·참고 문서와 확인하지 못한 범위를 구분합니다. 프로젝트 자체 코드의 전체 작성 이력이나 모든 과거 참고 출처를 복원한 기록은 아닙니다.

새 외부 코드를 편입할 때는 파일 경로, 원본 URL, 버전 또는 커밋, 라이선스, 복사·수정 범위를 기록하고 원래 고지를 함께 보존합니다. 출처·허가를 확인할 수 없는 코드는 그대로 추가하지 않습니다.
